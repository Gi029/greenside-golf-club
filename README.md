# GreenSide — Landing de club de golf

Landing page responsive para un club de golf (GreenSide), maquetada a partir
de un diseño dado (incluido en el repo como PDF). Sobre la base del diseño
original, adapté imágenes y botones para mejorar la coherencia visual del
conjunto.

## Tecnologías
- HTML semántico
- SCSS (Sass) compilado a CSS
- Responsive (mobile-first)

## Estructura
- `index.html` — estructura de la página
- `style.scss` — hoja de estilos fuente
- `style.css` — CSS compilado
- `img/` — recursos gráficos
- `Practica_6R.pdf` — diseño original de la práctica
